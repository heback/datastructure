8주차 탐구 활동지 — 트리와 이진 탐색 트리(BST)

핵심질문: 데이터가 1차원이 아닌 족보나 조직도처럼 뻗어나갈 때, 어떻게 저장하고 가장 빨리 탐색할까? 각 활동에서 관찰 → 정리 → 일반화 초안 순서로 직접 기록한다. 확인할 내용은 활동을 마친 뒤 여는 초록색 상자에만 있다. 빈칸은 스스로 채운다.

학번·이름은 위쪽 저장 바에 쓴다.

이론A1A2A3A4A5A6A7A8A9A10목록

이론 정리수업 전 예습 · 활동 중 참고 · 별도 활동 시간 없음

입력란이 없는 읽기 자료이다. 활동에서 구하는 값과 정리할 문장은 여기에 없다. 활동을 마친 뒤 확인하는 정리는 마지막 활동지(student_workbook_part2.html)의 맨 끝에 있다.

이론 정리 · 배경 지식

1. 계층 구조와 트리 리스트는 값을 한 줄로 늘어놓는다. 폴더 안의 폴더, 조직도처럼 값이 다른 값의 ‘아래’에 놓이는 데이터를 나타내는 자료구조가 트리(tree)이다. 트리는 노드(node)와 노드 사이의 연결(간선)로 이루어지며, 노드 하나는 값 하나와 자기 아래 노드로 가는 연결을 가진다.

2. 용어 활동 A2에서 트리 그림에 직접 라벨을 붙인 뒤 확인용으로 읽는다. 아래 예시 그림은 수업 활동에서 쓰는 트리와 다른 것이다.

        P
       / \
      Q   R
     /
    S
  • 루트(root): 맨 위에 있는 노드로, 부모가 없다. 예시에서는 P이다.
  • 부모·자식: 위아래로 바로 이어진 두 노드에서 위가 부모, 아래가 자식이다.
  • 리프(leaf): 자식이 없는 노드이다.
  • 서브트리(부분 트리): 어떤 노드를 맨 위로 삼았을 때 그 아래로 이어지는 부분이다.
  • 높이: 이 수업에서는 루트에서 가장 깊은 노드까지 지나는 노드의 수로 센다(예시는 3).
  • 이진 트리: 노드마다 자식이 최대 두 개(왼쪽, 오른쪽)인 트리이다. 이진 탐색 트리(BST)는 값의 크기 순서에 따라 노드를 배치해 탐색을 빠르게 하려는 이진 트리이다. 배치 규칙은 활동 A7에서 다룬다.

3. 순회란 트리의 모든 노드를 빠짐없이 한 번씩 방문하는 일이다. 트리는 갈래가 있으므로 방문 순서를 정해야 한다. 전위·중위·후위 순회로 나뉘며, 각 순서는 활동 A3에서 직접 쓴다.

4. 재귀와 기저 조건 트리는 ‘자식 아래의 트리도 똑같은 트리’라는 성질이 있어서 함수가 자기 자신을 불러 쓰는 재귀(recursion)가 잘 맞는다. 재귀 함수에는 더 부르지 않고 끝내는 자리인 기저 조건이 있어야 하고, 트리에서는 보통 빈 자리(None)이다. 가장 나중에 부른 호출이 가장 먼저 끝난다(호출 스택).

5. 파이썬 문법 노드는 클래스로 만든다. 없는 자식은 None으로 두고, is None으로 확인한다. 아래는 노드 값을 모두 더하는 작은 예이다.

class Node:
    def __init__(self, val, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

def total(node):
    if node is None:          # 기저 조건
        return 0
    return node.val + total(node.left) + total(node.right)

t = Node(4, Node(2), Node(7, None, Node(1)))
print(total(t))               # 14
print(total(None))            # 0
print(t.left.val, t.right.left)   # 2 None

함수 정의의 left=None처럼 매개변수에 = 값을 쓰면 인자를 생략했을 때 그 값을 쓴다(기본 인자).

6. 시간 복잡도 표기 읽기 입력의 크기를 N(노드 수, 값의 개수)이라 할 때 작업 횟수가 N에 따라 어떻게 늘어나는지를 O( )로 적는다. 상수 배와 작은 항은 빼고 가장 크게 늘어나는 모양만 쓴다.

  • O(1): N과 상관없이 일정하다.
  • O(log N): 한 번 할 때마다 남은 양이 절반쯤으로 줄어든다. 예: N이 1024이면 약 10번(log₂1024 = 10), 약 100만이면 약 20번이다.
  • O(N): N에 비례한다. N이 두 배이면 작업도 두 배이다.
  • O(h): 트리의 높이 h에 비례한다.

용어정의
트리(tree)노드와 간선으로 이루어진 계층 구조. 루트에서 다른 모든 노드로 가는 경로가 하나뿐이며 순환하지 않는다.
노드 / 간선노드(node): 데이터를 담는 단위. 간선(edge): 노드와 노드를 잇는 선(부모–자식 연결).
루트(root)부모가 없는 맨 위 노드(트리에 하나).
부모 · 자식 · 형제부모(parent)·자식(child): 간선으로 바로 위·바로 아래에 연결된 노드. 형제(sibling): 부모가 같은 노드.
리프(leaf)자식이 없는 노드.
서브트리(부분 트리)어떤 노드와 그 아래의 모든 노드로 이루어진 트리, 즉 트리 안의 트리.
이진 트리각 노드의 자식이 최대 2개(왼쪽·오른쪽)인 트리.
깊이(레벨) · 높이깊이(레벨): 루트를 1로 하고 아래로 내려갈수록 1씩 커지는 층 번호. 높이: 가장 큰 깊이, 즉 루트에서 가장 깊은 노드까지의 노드 수(T1의 높이는 3). 간선 수로 세면 1 작은 값이 나오지만 이 수업은 노드 수 기준으로 통일한다.

개념 정리 · 순회(traversal)

순회란 트리의 모든 노드를 한 번씩 방문하는 규칙이다. 방문 순서를 정하는 규칙에 따라 이름이 나뉜다. 여기서는 전위 규칙만 주어지고, 중위와 후위의 규칙은 이름에서 짐작해 직접 쓴다.

쓰는 법: 중위·후위 칸에는 “자신”, “왼쪽 부분 트리”, “오른쪽 부분 트리” 세 가지를 방문하는 순서대로 → 로 이어 쓴다. 세 가지를 한 번씩 모두 쓴다. 틀려도 된다.

이름방문 순서
전위 (Pre-order)자신 → 왼쪽 부분 트리 → 오른쪽 부분 트리
중위 (In-order)
후위 (Post-order)

짐작이 맞는지는 아래 순회 결과를 모둠에서 비교하고 2차시 코드 실행(A6·A8)에서 확인한다. 다르면 위 칸을 고쳐 쓴다. (1차시 A4 모둠 비교에서 결과가 서로 다르면 어느 규칙을 썼는지 먼저 맞춰 본다.)

  • 왼쪽·오른쪽 부분 트리에도 같은 규칙을 재귀로 적용한다.
  • 빈 트리(None)를 만나면 아무것도 하지 않고 돌아온다(기저 조건).
  • 재귀 복습: 함수가 자기 자신(더 작은 문제)을 호출하는 것.
  • 호출 스택: 호출된 함수들이 쌓이는 곳. 가장 나중에 호출된 것이 먼저 끝난다(LIFO).
학습 내용 · 호출 추적표 쓰는 법

추적표의 한 줄은 함수 호출 한 번이다. 호출이 시작된 순서대로 쓰고, 한 호출이 끝나야 그 호출을 부른 쪽으로 돌아온다. 빈 자리(None)로 향하는 호출도 한 줄이다. 방문은 호출되어 들어가는 것이고, 출력은 값을 쓰는 것이다. 부모를 거쳐야 자식으로 갈 수 있으므로 A B C D E F처럼 층별로 읽지 않는다.

예(T1이 아닌 노드 두 개짜리 트리 Node("X", Node("Y"))): 전위 규칙의 앞 3줄이다.

호출 순서호출한 노드이 호출에서 한 일지금까지 출력
1X출력 후 왼쪽 호출X
2Y출력 후 왼쪽 호출X Y
3None (Y의 왼쪽)바로 반환X Y

이어서 Y의 오른쪽 호출, X의 오른쪽 호출도 같은 방식으로 쓴다. 가장 나중에 시작한 호출이 가장 먼저 끝난다(호출 스택, LIFO). T1의 1단계(처음 4번 호출까지) 쌓인 모양이다. 마지막 호출은 None이라 바로 돌아간다.

세 순회의 약속 순회는 트리의 모든 노드를 한 번씩 방문하는 규칙이며, 세 순회는 ‘자기 값을 언제 출력하느냐’만 다르다. 번호는 일하는 순서이다.

전위① 출력(자신) → ② 왼쪽 부분 트리 순회 → ③ 오른쪽 부분 트리 순회
중위① 왼쪽 부분 트리 순회 → ② 출력(자신) → ③ 오른쪽 부분 트리 순회
후위① 왼쪽 부분 트리 순회 → ② 오른쪽 부분 트리 순회 → ③ 출력(자신)
  • T1의 결과: 전위 A B D E C F / 중위 D B E A C F / 후위 D E B F C A
  • 호출 순서(∅는 None 호출): A, B, D, ∅, ∅, E, ∅, ∅, C, ∅, F, ∅, ∅ → 모두 13번 = 노드 6개 + None 호출 7번이다. 노드가 N개이면 호출은 2N+1번(노드마다 1번, 빈 자리는 N+1번)이므로 순회의 시간은 노드 수 N에 비례한다.
  • (선택 질문) A는 왼쪽으로 가기 전에 출력했다. 자식이 없어 None이면 기저 조건에 따라 아무것도 하지 않고 호출한 곳으로 돌아간다.

개념 정리 · 이진 탐색 트리(BST)

이진 트리는 각 노드의 자식이 최대 2개(왼쪽·오른쪽)인 트리이다. 그중 모든 노드에서 왼쪽 부분 트리의 모든 값 < 그 노드의 값 ≤ 오른쪽 부분 트리의 모든 값을 만족하는 트리를 이진 탐색 트리(BST)라 한다(같은 값은 오른쪽에 둔다).

예측 10의 왼쪽에 5가 있고, 5의 오른쪽에 12가 있는 트리가 있다. 부모와 자식의 비교는 5 < 10, 12 > 5로 모두 맞는다. 이 트리는 BST인가? 그렇게 생각하는 이유를 쓴다.

쓰는 법: 먼저 “BST이다”나 “BST가 아니다”를 쓰고, 이유를 한 문장으로 잇는다.

이유를 쓴 뒤에 열어 짝과 확인한다

12는 5의 오른쪽 자식이지만 10의 왼쪽 부분 트리에 있다. 위 정의가 요구하는 것은 부모와의 비교만인가, 다른 노드와의 관계까지인가? 내 이유가 이 점을 짚었는지 짝과 비교해 보고, 다르면 위 칸을 고쳐 쓴다.

BST 삽입 규칙 카드 빈 트리에서 시작한다. 새 값은 루트부터 비교하여 노드의 값보다 작으면 왼쪽, 같거나 크면 오른쪽으로 내려간다. 내려갈 자리가 비어 있으면 거기에 새 노드를 놓는다.
학습 내용 · 삽입 경로 쓰는 법과 BST의 예

BST의 예이다. 모든 노드에서 왼쪽 부분 트리의 값은 그 노드보다 작고, 오른쪽 부분 트리의 값은 그 노드보다 크거나 같다(12 아래의 10은 12보다 작고 루트 8보다 크다).

        8
      /   \
     3     12
    / \   /  \
   1   6 10   15

A10 · 일반화 초안 카드2차시 · 3분 · 개인

개인 메모 · 이 카드는 A13에서 모둠이 함께 정제한다

학습 내용 · 일반화 문장을 쓰는 방법
  • 일반화 문장은 한 사례의 사실이 아니라 여러 사례에 통하는 개념 + 개념 + 관계이다. 사례 이름(T1, 8, 폴더 이름)은 개념어로 바꾼다.
  • 쓸 수 있는 개념어: 루트·리프·높이 / 순회 / 삽입 / 재귀 / 정렬 조건(BST) / 입력 순서 / 탐색 횟수 중 두 개 이상.
  • 사례 서술과 개념 문장의 차이(트리와 무관한 예): “우리 모둠 발표는 3분이 걸렸다.”는 사례 서술이고, “준비한 분량이 많을수록 시간 초과 위험이 커진다.”는 개념 문장이다.
  • 쓴 뒤 점검: 개념어가 2개 이상인가, 관계를 나타내는 말(~이면, ~하므로, ~에 따라)이 있는가, 사례 이름을 지워도 말이 되는가. 오늘 활동 가운데 가장 크게 생각이 바뀐 것 하나만 골라 쓴다.

오늘의 발견을 “개념 + 개념 + 관계” 문장 하나로 쓴다. 완성되지 않아도 괜찮다.

쓰는 법: 개념 두 개 이상이 들어간 한 문장(길어도 두 문장)으로 쓴다. 쓴 만큼만 써도 된다.
