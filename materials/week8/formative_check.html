Q1~Q3 · 가변 기본 인자 코드수업 시간 A15 · 10점

아래 코드는 6개 값 [35, 18, 52, 11, 27, 60]을 차례로 삽입한 BST(T7)에서 자식이 없는 노드(리프)의 값을 모으는 코드이다. Node, insert, build는 수업에서 쓴 것과 같다. 이 문항지의 코드는 읽고 푸는 문제이다.

class Node:
    def __init__(self, val, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

def insert(root, val):          # BST 삽입 (A7)
    if root is None:
        return Node(val)
    if val < root.val:
        root.left = insert(root.left, val)
    else:
        root.right = insert(root.right, val)
    return root

def build(values):              # 값 목록을 차례로 삽입해 BST를 만든다
    root = None
    for v in values:
        root = insert(root, v)
    return root
def collect_leaves(node, leaves=[]):
    if node is None:
        return leaves
    if node.left is None and node.right is None:
        leaves.append(node.val)
    collect_leaves(node.left, leaves)
    collect_leaves(node.right, leaves)
    return leaves

t7 = build([35, 18, 52, 11, 27, 60])

print(collect_leaves(t7))
print(collect_leaves(t7))
학습 내용 · 문항 푸는 방법
  • 코드는 읽고 푸는 문제이며 실행은 선택이다. 이 함수는 트리 T7에서 자식이 없는 노드(리프)의 값만 모아 리스트로 돌려준다. T7의 모양은 아래와 같다.
        35
       /  \
     18    52
    /  \     \
  11    27     60
  • Q1은 두 print 줄의 출력을 차례로 리스트로 쓴다(값과 개수). Q2는 버그가 있는 줄을 지목하고 원인을 한 문장으로 쓴다. Q3은 수정한 함수 전체를 편집기에 쓴다. 호출은 collect_leaves(t7)처럼 인자 하나로 할 수 있어야 하고, 몇 번을 호출해도 결과가 항상 같아야 한다.
  • 시간은 약 6분이다. 혼자 풀고 AI는 쓰지 않는다.

아래 이진 트리가 있다.

민수는 “3의 왼쪽 자식 1은 3보다 작고, 오른쪽 자식 9는 3보다 크며, 8의 왼쪽 자식 3은 8보다 작고, 오른쪽 자식 10은 8보다 크다. 그러므로 BST이다.”라고 판단하였다.

Q5 · 보조 문항: 재귀 순회 코드 점검수업 밖 선택·과제 · 3점

아래 코드를 실행하면 어떻게 되는지 쓰시오. 원인이 되는 부분을 지적하고, 고쳐 쓰시오. Node, insert, build는 Q1의 것과 같다.

def inorder(node, out):
    inorder(node.left, out)
    out.append(node.val)
    inorder(node.right, out)
    return out

print(inorder(build([2, 1, 3]), []))
