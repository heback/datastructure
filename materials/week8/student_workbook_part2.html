코드: student_code_lab_part2.html A12수행지시어 수정하다 · 산출물: 수정된 함수 + 한 줄 원인 설명

학습 내용 · 관찰 방법과 수정 조건
  • 함수이름.__defaults__는 파이썬이 함수에 저장해 둔 기본 인자 값들을 튜플로 보여 준다. 예: def f(a, b=5)이면 f.__defaults__는 (5,)이다. 호출 전과 후의 출력을 표에 옮기고, 달라진 점에서 ‘기본값이 언제 만들어지는가’를 추론한다.
  • 수정 조건(테스트 기준): 호출은 collect_inorder(t)처럼 인자 하나, 같은 트리를 몇 번 불러도 같은 결과, 다른 트리를 불러도 섞이지 않음, __defaults__ 안에 리스트가 남아 있지 않음.
  • 수정 방향: 호출마다 새로 만들어져야 하는 것은 결과 리스트이다. 수정 방법은 여러 가지이며 대안 비교에서 견준다.
  • 시간은 약 10분이며 관찰 4분, 수정 4분, 대안 비교 2분으로 나눈다.

방법 이름호출하는 모습좋은 점대가

생각해 볼 질문 위에 쓴 세 방법 가운데 함수 안에 조건문(if)이 필요 없는 방법은 어느 것인가? 그 방법은 어떤 대가를 치르는가?

활동을 마친 뒤 열어 확인한다 · 원인, 수정, 대안
  • 원인: 기본값 []은 def가 실행되어 함수가 만들어질 때 한 번만 만들어져 함수에 저장되고, 모든 호출이 같은 리스트를 공유한다. __defaults__가 ([],)에서 호출 뒤 값이 든 리스트로 바뀐 것이 증거이다. 한 번의 순회 안에서는 재귀 호출이 visited를 명시적으로 넘겨 정상으로 보이다가, 인자 없이 부르는 두 번째 호출에서 드러난다.
def collect_inorder(node, visited=None):
    if visited is None:      # 인자를 주지 않았을 때만 새 리스트를 만든다
        visited = []
    if node is None:         # (나머지 줄은 그대로)
        return visited
방법좋은 점대가
None 센티널호출이 간단하다함수 안에 None 검사 두 줄이 필요하다
결과 리스트를 인자로 받기(A6 방식)기본값이 없어 안전하다호출하는 쪽이 매번 []를 만들어 넘겨야 한다
내부 헬퍼 함수 / 제너레이터호출이 간단하고 안전하다함수 안에 함수가 하나 더 생기거나 list()로 감싸야 한다
  • 잘못된 수정 두 가지: 호출할 때마다 []를 직접 넘기면 그 호출은 맞지만 인자 없이 부르면 다시 누적된다. 함수 안에서 무조건 visited = []를 쓰면 재귀 호출마다 새 리스트가 생겨 결과가 사라진다.
  • 어느 방법이 낫다는 정답은 없고, 치르는 대가를 말할 수 있으면 된다.

① 부모보다 왼쪽 자식이 작고 오른쪽 자식이 크면 BST이다.
② BST에서 탐색은 항상 O(log N)이다.
③ 함수의 기본값 []는 호출할 때마다 새로 만들어진다.

(선택) 위 세 진술 중 오늘 처음 생각을 바꾼 것은 몇 번이며, 바꾸게 한 활동은 무엇인가?

먼저 위 표와 칸에 자기 판단을 쓴 뒤 연다.

활동을 마친 뒤 열어 확인한다 · 오개념 점검 진술의 답
  • ① 거짓: 부모와의 비교만 맞아도 BST가 아닐 수 있다(A7의 10 아래 5, 5의 오른쪽 12). 모든 부분 트리에서 성립해야 한다.
  • ② 거짓: 균형일 때만 O(log N)이고 T5처럼 쏠리면 O(N)이다(A9).
  • ③ 거짓: 기본값 []은 함수가 정의될 때 한 번만 만들어져 모든 호출이 공유한다(A11·A12).

학습 내용 · AI 활용 내역을 쓰는 방법
  • AI를 쓰지 않았으면 체크 칸만 체크하고 표는 비운다.
  • 쓴 경우 한 줄에 한 번의 질문을 쓴다. 질문 요약에는 AI에게 무엇을 시켰는지, 단계에는 허용 또는 조건부 허용, 반영 여부와 이유에는 답을 코드·글에 반영했는지(채택·미채택)와 그 이유를 쓴다.
  • 기준은 “AI에게 무엇을 시켰는가”이다. 개념·문법·오류 원인을 묻는 것은 허용이고, 내가 쓴 코드의 검토·엣지 케이스·개선 아이디어는 조건부 허용(출처와 반영 여부 필수)이다. 과제 전체 코드 생성, 구현 계획·누적 방식의 대신 설계, 수업 중 A6·A14·A15의 AI 사용, 성찰일지 대필은 금지이므로 이 표에 쓰는 항목이 아니다.
  • 기록 예: “빈 트리 테스트를 제안받음 → 채택, 이유: 기저 조건 확인에 필요했다”
