A2 · 같은 관계를 두 가지로 적어 보기 (G1)1차시 · 14분 · 짝

산출물: 6×6 표, 노드별 이웃 목록

약속 · 용어
  • 노드: 관계를 맺는 대상(사람, 페이지, 역). 간선: 두 노드를 잇는 관계 한 개. 노드와 간선을 모은 것이 그래프이다.
  • 무방향: 간선에 방향이 없다(친구 관계처럼 서로 같다). 방향: 간선에 출발과 도착이 있다(링크처럼 한쪽으로 간다).
  • 인접 행렬: 모든 쌍의 자리를 칸으로 둔 표이다. 연결이면 1, 아니면 0을 적는다.
  • 인접 리스트: 노드마다 이웃 목록을 둔다. 존재하는 간선만 적는다.

G1 · 친구 관계: 노드 A~F, 간선 5개(무방향) (A,B) (A,C) (B,D) (C,D) (D,E). 노드 F는 아무와도 이어져 있지 않다.

   A ─ B
   │   │
   C ─ D ─ E        F
학습 내용 · 작은 예로 보는 표와 목록 적는 방법

노드 P, Q, R과 간선 (P,Q), (Q,R)이 있는 무방향 그래프를 두 방식으로 적으면 다음과 같다. 행은 “어디에서”, 열은 “어디로”이다.

     P  Q  R          P: Q
  P [0  1  0]         Q: P, R
  Q [1  0  1]         R: Q
  R [0  1  0]
  (인접 행렬)         (인접 리스트)
  • 표에서 Q행 R열이 1이면 Q에서 R로 이어져 있다는 뜻이다. 간선 (Q,R)을 표에 어떻게 적을지는 위 예를 보고 스스로 판단한다.
  • 이웃은 간선으로 바로 이어진 노드이다. 위 예에서 Q의 이웃은 P와 R이다.
  • 표는 간선을 하나씩 보며 해당 칸에 1을 적고 나머지 칸은 0으로 둔다. 목록은 노드마다 이웃을 모두 적는다. 한 간선을 넣으면 표에서 몇 칸이, 목록에서 몇 군데가 바뀌는지 세어 본다.
  • 표를 다 적은 뒤 1이 적힌 칸의 수를 세어 둔다. A5에서 쓴다.

A4 · 두 표현의 비용 비교표 (COST)1차시 · 16분 · 모둠

산출물: 비교표 + 가설 메모

약속 · 세는 방법
  • 질의 ① u–v 간선이 있나: 확인한 칸 또는 원소의 수. 목록에서는 u의 이웃 목록을 앞에서부터 하나씩 보며 v를 찾으면 멈추고, 없으면 목록 전체를 본다.
  • 질의 ② u의 이웃을 모두 찾기: 훑어 본 칸 또는 원소의 수. 표에서는 u의 행 전체를 훑는다.
  • 질의 ③ 저장 공간: 표의 칸 수 / 목록의 원소 수.
  • 밀도 = 간선 수 ÷ 가능한 쌍의 수. 무방향 그래프의 가능한 쌍은 N(N−1)/2이다. 간선이 적으면 희소, 많으면 밀집이라고 한다.
학습 내용 · 칸과 원소를 세는 작은 예

A2의 작은 예(노드 P, Q, R, 간선 (P,Q), (Q,R))로 세어 본다.

  • ③ 저장: 표의 칸 수와 목록의 원소 수를 센다. 예의 목록은 P: Q / Q: P, R / R: Q이다.
  • ① P–R 간선 확인: 표는 P행 R열 1칸만 본다. 목록은 P의 목록 [Q]를 앞에서부터 보며 R을 찾는다. Q 하나를 보고 R이 없으므로 1원소이다.
  • ② Q의 이웃 모두: 표는 Q행 3칸을 훑는다. 목록은 Q의 목록 원소 2개를 본다.
  • 평균 이웃 수는 노드 하나의 목록에 평균 몇 개의 이웃이 있는가이다. 식은 G1, SPARSE, DENSE의 값을 나란히 놓고 세 값에 모두 맞는 계산을 시험해 찾는다.

  • 정답은 10칸이다. 무방향 간선 하나는 (i,j)와 (j,i)의 두 칸에 1이 들어가므로 간선 수 5의 2배이다. 인접 리스트에도 간선 하나가 두 원소로 들어간다.
  • 1차시 정리: 노드와 간선을 모은 것이 그래프이고, 간선에 방향이 없으면 무방향, 있으면 방향이다. 인접 행렬은 모든 쌍의 자리를 칸으로 둔 N×N 표이고, 인접 리스트는 노드마다 이웃 목록을 두어 존재하는 간선만 적는다. 우리가 센 값은 저장한 칸 수·원소 수와 확인한 칸 수·원소 수(A4 비교표)이다. 표현 선택의 판정은 A12에서 정리한다.
