손 표와 코드가 같은지 볼 때는 모든 (i, j)에서 m[i][j] == m[j][i]인지 확인하면 대칭 여부를 알 수 있다. 노드 이름 “A”의 칸 번호는 번호표 MAP["A"]로 안다.

m = [[0] * 3] * 3
m[0][1] = 1
print(m)   # [[0, 1, 0], [0, 1, 0], [0, 1, 0]]
m = [[0] * 3 for _ in range(3)]
m[0][1] = 1
print(m)   # [[0, 1, 0], [0, 0, 0], [0, 0, 0]]

원인: [[0] * 3] * 3은 같은 행 리스트 하나를 3번 가리킨다(같은 행 3번). 한 행을 바꾸면 세 행이 함께 바뀐다. for _ in range(3)로 행마다 새 리스트를 만들면 행이 따로 3개가 된다.

def make_matrix(n):
    return [[0] * n for _ in range(n)]
def add_edge(m, u, v):
    m[u][v] = 1
    m[v][u] = 1   # 무방향이므로 두 칸에 모두 적는다
