대칭인지 코드로 확인

무방향 그래프의 행렬은 대칭이다. 노드 P, Q, R(번호 0, 1, 2)의 작은 표로 보자.

     0  1  2
  0 [0  1  0]
  1 [1  0  1]
  2 [0  1  0]

m[0][1]과 값이 같아야 하는 칸은?

(0,1)을 쓰면 (1,0)에도 1을 쓴다. 두 칸이 같아야 대칭이다.

행렬 전체가 대칭인지 코드로 확인하는 방법을 한두 문장이나 코드 한 줄로 쓴다.

노드 이름 “A”가 몇 번 칸인지 알려면?

이름을 번호로 바꾸는 번호표(예: {"A": 0, "B": 1, …})를 만들어 쓴다.

활동을 마친 뒤 열어 확인한다 · 한 칸을 바꿨는데 여러 칸이 바뀌는 이유와 참조 코드

손 표와 코드가 같은지 볼 때는 모든 (i, j)에서 m[i][j] == m[j][i]인지 확인하면 대칭 여부를 알 수 있다. 노드 이름 “A”의 칸 번호는 번호표 MAP["A"]로 안다.

m = [[0] * 3] * 3
m[0][1] = 1
print(m)   # [[0, 1, 0], [0, 1, 0], [0, 1, 0]]
m = [[0] * 3 for _ in range(3)]
m[0][1] = 1
print(m)   # [[0, 1, 0], [0, 0, 0], [0, 0, 0]]

원인: [[0] * 3] * 3은 같은 행 리스트 하나를 3번 가리킨다(같은 행 3번). 한 행을 바꾸면 세 행이 함께 바뀐다. for _ in range(3)로 행마다 새 리스트를 만들면 행이 따로 3개가 된다.

def make_matrix(n):
    return [[0] * n for _ in range(n)]
def add_edge(m, u, v):
    m[u][v] = 1
    m[v][u] = 1   # 무방향이므로 두 칸에 모두 적는다

C5 (선택) 기본 인자

함수의 기본 인자 g={}를 쓰고, 함수를 두 번 부른다. 출력 세 줄을 예측한다.

def build(edges, g={}):
    for u, v in edges:
        g.setdefault(u, []).append(v)
    return g

a = build([("A", "B")])
b = build([("C", "D")])
print(a)
print(b)
print(a is b)
