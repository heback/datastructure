활동을 마친 뒤 열어 확인한다 · 점검 케이스 기대값, 참조 코드, SUB 확인
  • 1 build_graph(G1 간선) → {'A':['B','C'],'B':['A','D'],'C':['A','D'],'D':['B','C','E'],'E':['D']}이고 defaultdict. 2 list(neighbors(g,"D")) → ['B','C','E']이고 제네레이터. 3 list(neighbors(g,"Z")) → []이고 g는 호출 전과 같으며 "Z" not in g. 4 같은 it를 두 번 list → 두 번째는 [].
  • 5 build_graph(W, directed=True) → {0:[1,2],1:[2],2:[0],3:[2]}, list(neighbors(g,2)) == [0], list(neighbors(g,1)) == [2]. 6 build_graph([]) → {}. 7 build_graph([(1,2),(2,3)], True)에서 3 not in g이고 list(neighbors(g,3)) == []를 한 뒤에도 3 not in g(끝 노드는 이웃이 없는 노드이지만 간선 출발점으로 나온 적이 없어 g의 키가 아니다). 8 list(neighbors(g,"다")) → ['나','라','바','사'].
from collections import defaultdict
def build_graph(edges, directed=False):
    g = defaultdict(list)
    for u, v in edges:
        g[u].append(v)
        if not directed:
            g[v].append(u)
    return g
def neighbors(g, u):
    if u in g:
        yield from g[u]
  • SUB: 노드 8개, 간선 7개이다. 다의 이웃은 나, 라, 바, 사로 4개이고 차수가 3 이상인 역은 다 하나뿐이다. 환승역은 각 노드의 이웃 수를 세어 찾는다. 모두 연결되어 있고 돌아오는 길이 없으며 간선 7 = 노드 8 - 1이므로 트리이다.
  • SUB+(마,아 추가): 간선 8개이고 여전히 연결되지만 다→라→마→아→사→다로 돌아오는 길이 생겨 트리가 아니다. 마의 이웃은 ['라','아'], 아의 이웃은 ['사','마']이고 이웃 원소의 합은 14에서 16으로 는다.

AI 활용 3단계 · 이 과제에 맞춘 예허용 · 조건부 허용 · 금지

기준은 “AI에게 무엇을 시켰는가”이다. 개념·문법·오류 원인을 묻는 것은 허용이고, 과제 요구사항이나 완성된 구현을 입력해 결과물(코드·글)을 받아 제출하는 것은 금지이다.

허용
  • 용어 번역·개념 요약, 수업 자료 복습 질문
  • “defaultdict(list)와 일반 dict는 뭐가 달라?”, “yield를 쓰면 함수가 어떻게 달라져?” 같은 개념·문법 질의
  • “KeyError: ‘A’가 왜 나와?”, “TypeError: first argument must be callable or None의 의미는?” 같은 오류 메시지 해설
  • “인접 행렬과 인접 리스트는 보통 어디에 쓰는지 용어 설명해 줘” 같은 용어·설계 배경 설명
  • 내 코드 결과가 점검과 다를 때 원인 힌트만 요청
조건부 허용
  • 내가 완성한 구현의 엣지 케이스 브레인스토밍(빈 간선 목록, 고립 노드, 중복 간선, 방향/무방향, 없는 노드 질의)
  • 내가 쓴 neighbors의 동작을 엣지 케이스별로 검토 요청(수정은 직접 한다)
  • 내 코드의 개선 아이디어 제안 요청(제안만 참고하고 코드는 직접 다시 작성)
  • 내가 쓴 구현의 시간·공간 복잡도 검토 요청(복잡도는 내가 먼저 쓴 뒤 검토만 받고, 고쳐 쓰기는 직접 한다)
금지 — 적발 시 계획서의 위반 처리방안 적용
  • 과제 문장(“defaultdict(list)로 그래프를 만들고 제네레이터로 이웃을 반환하라”)을 그대로 입력해 전체 코드 생성
  • AI가 쓴 build_graph/neighbors를 그대로, 또는 변수명만 바꿔 제출
  • 두 표현 중 무엇을 쓸지, 예외 상황을 어떻게 처리할지 등 설계 판단을 AI가 대신 내림
  • 복잡도 분석이나 구현 계획을 AI에게 대신 세우게 하여 제출
