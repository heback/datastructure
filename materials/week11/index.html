학습활동 자료수업 진행 순서

활동지는 화면에 입력해 풀고 [저장(JSON)]으로 낸다. 종이에 쓰는 것은 메모 용도로만 한다(종이로 쓴 내용은 제출되지 않는다). 코드 실행이 필요한 활동은 화면에서 한다.

입력하고 제출하기입력 → 저장 → 제출

  1. 입력: 화면의 입력란에 쓰고, 위쪽 저장 바에 학번과 이름을 쓴다. 실습 코드 파일의 코드 입력란은 편집기이다. [▶ 실행]으로 브라우저에서 실행하고, 다른 쪽의 코드가 필요하면 [앞 쪽 코드 불러오기]를 누른다. 편집기의 내용은 [저장(JSON)]에 함께 들어간다.
  2. 저장: [저장(JSON)] 단추를 누르면 JSON 파일 한 개가 내려받아진다.
  3. 제출: 내려받은 JSON 파일을 안내받은 방법(예: LMS)으로 낸다. 파일마다 한 번씩 한다.

이번 주차에 저장·제출하는 파일은 모두 7개이다(rubric.html은 읽는 자료라 제출하지 않는다).

시간이 모자라면 [임시 저장]을 눌러 파일을 내려받아 둔다. 다음에 같은 파일을 열고 [불러오기]로 그 파일을 고르면 쓴 내용이 돌아와 이어 쓸 수 있다. 임시 저장 파일은 제출 파일이 아니다. 다 쓴 뒤 [저장(JSON)]으로 만든 파일(파일명에 “임시저장”이 없는 것)을 낸다.
