11주차 탐구 활동지 1부 — 이웃으로 계속 나아가며 돌아보기 (A1~A5)

핵심질문: 미로에서 출구를 찾거나 특정 구역이 얼마나 연결되어 있는지 확인할 때, 어떤 순서로 탐색하는 것이 정답일까? 각 활동에서 관찰 → 정리 → 일반화 초안 순서로 직접 기록한다. 확인할 내용은 활동을 마친 뒤 여는 초록색 상자에만 있다. 빈칸은 스스로 채운다.

학번·이름은 위쪽 저장 바에 쓴다.

이론 정리수업 전 예습 · 활동 중 참고 · 별도 시간 없음

이론 정리 · 배경 지식
  • 탐색(순회)이란: 그래프의 한 노드에서 출발해 간선으로 이어진 이웃으로 한 걸음씩 나아가며 노드를 살펴보는 일이다. 길 찾기, 몇 단계 만에 닿는지 세기, 이어진 덩어리 세기가 모두 이 일에 속한다. 노드 하나를 살펴보는 것을 방문이라고 한다. 오늘은 “어느 이웃을 어떤 순서로 방문할 것인가”를 직접 알아낸다.
  • 그래프와 이웃: 점(노드)과 선(간선)으로 이루어진다. 파이썬에서는 딕셔너리로 노드마다 이웃 목록을 적는다(10주차). 한 걸음에 갈 수 있는 노드의 모임이 그 노드의 이웃이다.
  • 2차원 격자: 미로나 지도는 문자열 목록으로 나타내고 grid[행][열]로 한 칸을 읽는다. 위·아래·왼쪽·오른쪽 네 칸이 이웃이며, 이동량을 (행 변화, 열 변화) 쌍의 목록으로 적어 두고 반복한다. 가장자리 칸은 이웃이 격자 밖에 있을 수 있으므로 범위 검사가 필요하다.
  • 방문 기록: 이미 본 노드를 적어 두는 곳이다. 집합(set)은 “들어 있는가” 검사 x in seen이 빠르다.
  • 컨테이너: 앞으로 볼 노드를 잠시 담아 두는 자료구조이다. 5주차에서 배운 두 가지를 떠올린다. 스택은 가장 나중에 넣은 것을 먼저 꺼내고, 큐는 가장 먼저 넣은 것을 먼저 꺼낸다. 파이썬에서 스택은 list의 append와 pop(), 큐는 collections.deque의 append와 popleft()로 쓴다.
  • 재귀와 호출 스택: 함수가 자기 자신을 부르면 부른 함수가 끝날 때까지 호출 기록이 쌓였다가 거꾸로 사라진다(8주차). 이 기록이 쌓이는 곳이 Call Stack이다.
  • 시간복잡도 읽는 법: 입력 크기에 따라 작업 횟수가 어떻게 늘어나는지를 O(…)로 적는다. O(N)은 “개수 N에 비례해 늘어난다”, O(1)은 “개수와 상관없이 한 번에” 걸린다는 뜻이다. 그래프의 노드 수는 V, 간선 수는 E, 격자의 행·열 수는 R, C로 적는다.

작은 예 1 · 컨테이너 연산 (활동 데이터와 다른 값이다.)

from collections import deque
box = deque(["x", "y"])
box.append("z")
print(box)               # deque(['x', 'y', 'z'])
print(box.popleft(), box)  # x deque(['y', 'z'])
print(box.pop(), box)      # z deque(['y'])
print(len(box) == 0)       # False

작은 예 2 · 그래프 딕셔너리와 방문 기록

g = {"P": ["Q", "R"], "Q": ["P"], "R": ["P", "S"], "S": ["R"]}
print(g["R"])                  # ['P', 'S']
for nb in g["R"]:
    print("R의 이웃:", nb)     # R의 이웃: P / R의 이웃: S
seen = set()
seen.add("P")
print("P" in seen, "Q" in seen)  # True False

작은 예 3 · 격자의 네 이웃과 범위 검사

grid = ["..#",
        "#.."]
R, C = len(grid), len(grid[0])
print(R, C, grid[1][2])        # 2 3 .
DIRS = [(-1, 0), (1, 0), (0, -1), (0, 1)]
r, c = 1, 1
for dr, dc in DIRS:
    nr, nc = r + dr, c + dc
    if 0 <= nr < R and 0 <= nc < C:
        print((nr, nc), grid[nr][nc])
    else:
        print((nr, nc), "격자 밖")   # (0, 1) . / (2, 1) 격자 밖 / (1, 0) # / (1, 2) .

참고 위 예는 읽기용이다. 이웃을 도는 순서 규칙은 코드에 없다. 그 규칙은 활동에서 직접 만든다.

A2 · 컨테이너 두 가지로 손 탐색하기1차시 · 14분 · 짝

산출물: 두 방문 순서, 단계별 컨테이너 상태표

약속 · 용어와 규칙
  • 컨테이너: 앞으로 볼 노드를 담아 두는 곳이다. 스택은 맨 위(그림에서 오른쪽 끝)에서 꺼내고, 큐는 맨 앞(그림에서 왼쪽 끝)에서 꺼낸다. 큐에 넣는 쪽은 뒤(오른쪽)이다.
  • 방문: 컨테이너에서 꺼내 처리한 때이다. 방문 순서는 이 처리 순서이다(컨테이너에 들어간 순서가 아니다).
  • 방문 기록: 이미 방문한 노드를 적어 두는 곳이다.

손으로 탐색하는 규칙 (스택 규칙과 큐 규칙을 각각 따라 한다)

  1. 시작 노드를 컨테이너에 넣는다.
  2. 컨테이너에서 하나 꺼낸다. 이미 방문한 노드이면 버리고 다시 꺼낸다.
  3. 방문 기록에 쓰고, 그 노드의 이웃 중 아직 방문하지 않은 것을 목록 순서대로 컨테이너에 넣는다(스택은 위에, 큐는 뒤에).
  4. 컨테이너가 빌 때까지 반복한다.
학습 내용 · 손 규칙 작은 예와 표 쓰는 법

작은 그래프 X: 간선 (X,Y) (X,Z), 이웃 목록 X: [Y, Z] Y: [X] Z: [X]. 시작 X에서 스택 규칙을 따르면 다음처럼 쓴다(스택은 오른쪽 끝이 맨 위).

  ┌── Y            시작 상태: 컨테이너 [X], 방문 기록 비어 있음
X ┤
  └── Z            단계 1  꺼냄 X (방문)  → 컨테이너 [Y, Z]   (Y, Z를 목록 순서로 위에 넣음)
                   단계 2  꺼냄 Z (방문)  → 컨테이너 [Y]      (이웃 X는 방문했으므로 넣지 않음)
X: [Y, Z]          단계 3  꺼냄 Y (방문)  → 컨테이너 [ ]      (비었으므로 끝)
Y: [X]  Z: [X]     방문 순서: X, Z, Y
  • 용어: 이웃 순서는 인접 리스트 목록의 순서이다. 방문은 컨테이너에서 꺼내 처리한 때이고, 방문 기록은 방문한 노드를 적어 두는 곳이다.
  • 이웃을 넣을지는 방문 기록만 보고 정한다. 이미 컨테이너 안에 있어도 아직 방문하지 않았으면 넣는다.
  • 이미 방문한 노드를 꺼냈으면 결과 칸에 “이미 방문, 버림”이라고 쓰고 이웃은 넣지 않는다.
  • 짝 활동: 한 명은 스택 규칙, 한 명은 큐 규칙을 맡아 (가)(나) 표를 각각 쓰고, 끝나면 서로의 표를 검토한다. 칸이 비었거나 꺼내는 쪽이 뒤바뀐 곳을 찾는다.

A3 · 재귀로 돌아보기: 호출이 쌓이는 모습1차시 · 13분 · 짝

산출물: 재귀 호출 추적표, Call Stack 그림, 두 순서 비교 메모

같은 G1에서 시작 A로, 재귀 함수로 돌아본다. 방문 기록 visited와 방문 순서 order는 바깥에서 새로 만들어 인자로 전달한다.

def dfs(u):          # 의사코드
    visited에 u 추가, order에 u 기록
    for 이웃 v in (u의 이웃 목록 순서):
        if v가 visited에 없으면:
            dfs(v)
학습 내용 · enter·exit 추적 방법과 작은 예
  • enter는 함수 호출이 시작될 때, exit는 그 호출이 끝나 돌아올 때이다. 호출이 시작되면 Call Stack 맨 위에 그 호출이 쌓이고, 끝나면 맨 위가 사라진다. 깊이는 맨 처음 호출을 0으로 하고 호출 안에서 부른 호출마다 1씩 늘어난다.
  • Call Stack 칸은 아래부터 위로 [A, B]처럼 쓴다. exit 줄은 그 호출이 끝나 사라진 직후의 모습으로 쓴다(직전 모습으로 쓰려면 표 전체를 한 가지로 통일한다). 깊이는 끝난 호출의 깊이를 쓴다.
  • 의사코드는 이웃 목록을 앞에서부터 보다가 방문하지 않은 이웃을 만나면 그 자리에서 바로 호출한다. 호출이 끝나면 돌아와 목록의 다음 이웃을 이어서 본다. G1과 이웃 목록은 A2와 같다.

작은 그래프 P(P: [Q], Q: [P, R], R: [Q])에서 dfs(P)를 추적한 예이다.

시작 D에서 큐 규칙의 방문 순서는 D, B, C, E, A이므로 A는 5번째이다. D를 방문하며 B, C, E를 넣고, B를 방문하며 A를 넣고, C를 방문하며 A를 한 번 더 넣는다. A는 큐에 두 번 들어가지만 방문은 처음 꺼낸 때 한 번이고, 버려진 줄은 순서에 세지 않는다.
