A8 · 함정 탐색: 예측 후 실행13분 · 짝

각 코드의 위쪽 주석에 시작 상태가 적혀 있다. T 편집기는 실행할 때마다 그 코드의 함수를 처음부터 다시 정의하므로 새로 시작한 상태에서 실행된다(T4는 세 번의 호출이 한 번의 실행 안에서 이어진다). 같은 T 코드를 한 편집기에 두 번 추가하지 않도록 주의한다.

학습 내용 · T1~T4가 보여 주려는 것과 예측 쓰는 법
  • T1은 visited에 “봤다”고 표시하는 시점(큐에 넣을 때 / 꺼낼 때)을 바꿔 본다. T1-a는 G1에서 나온 방문 순서, T1-b는 열린 4×4 격자에서 (큐에 넣은 횟수, 큐 길이의 최댓값) 한 쌍을 두 방식으로 출력한다.
  • T2는 큐를 list로 만들어 pop(0)으로 꺼낼 때와 deque의 popleft()로 꺼낼 때를 비교한다. 시간은 환경마다 다르므로 “n이 10배가 될 때 시간이 몇 배가 되는가”를 본다. 10배 근처인지 아닌지를 예측한다.
  • T3은 한 줄로 이어진 땅(너비 500, 1500)을 재귀로 탐색한다. 한 줄로 이어진 땅이 길어지면 어떻게 되는지 두 너비의 결과를 예측한다. T4(선택)는 visited를 기본 인자 set()으로 둔 함수를 세 번 부른다.
  • 하는 방법: ① 코드를 읽고 활동지 2부 A8의 예측 칸을 먼저 쓴다 ② 편집기에서 실행해 실제 값을 쓴다 ③ 예측과 다르면 원인 한 줄을, 마지막 칸에는 실제 코드 어디서 만날지 한 줄을 쓴다. 오류가 나면 오류 이름과 메시지를 그대로 옮겨 적는다. 정리 질문을 마친 뒤 활동지 2부 A8의 확인 상자에서 값을 대조한다.

T1-a

# T1-a · 시작 상태: 큐 [start], visited는 비어 있다. g는 G1.
# g에서 start부터 방문 순서를 만드는 함수(bfs_late)이다.
def bfs_late(g, start):
    q = deque([start])  # 시작 노드만 든 큐
    visited = set()  # set: 중복 없이 담는 모음
    order = []  # 방문 순서를 담을 리스트
    while q:  # 큐가 비지 않은 동안 반복한다
        u = q.popleft()  # 큐의 맨 앞에서 꺼낸다
        visited.add(u)
        order.append(u)  # 꺼낸 노드를 순서에 기록한다
        for v in neighbors(g, u):  # u의 이웃을 하나씩 본다
            if v not in visited:
                q.append(v)  # 큐의 뒤에 넣는다
    return order

print(bfs_late(g, "A"))

T1-b

# T1-b · 시작 상태: 함수 안에서 매번 새 큐, seen. 격자는 모두 통과할 수 있는 4x4.
# 벽이 없는 4x4 격자(모든 칸이 '.')
OPEN4 = ["....", "....", "....", "...."]

# 격자를 BFS로 훑으며 (큐에 넣은 횟수, 큐 길이의 최댓값)을 센다.
# mark_when은 '봤다'고 표시하는 시점을 정하는 값이다.
def bfs_count(grid, start, mark_when):      # mark_when: "enqueue" 또는 "dequeue"
    enq = 1  # 큐에 넣은 횟수(시작 칸 포함)
    maxq = 1  # 큐 길이의 최댓값
    q = deque([start])
    seen = set()  # 봤다고 표시한 칸 모음
    if mark_when == "enqueue":
        seen.add(start)
    while q:
        u = q.popleft()
        if mark_when == "dequeue":
            if u in seen:  # 이미 표시된 칸인가
                continue  # 이번 반복을 건너뛰고 다음으로
            seen.add(u)
        # 통과할 수 있는 칸('.')의 이웃만 본다
        for n in grid_neighbors(grid, u[0], u[1], "."):
            if n not in seen:
                if mark_when == "enqueue":
                    seen.add(n)
                q.append(n)
                enq += 1
        maxq = max(maxq, len(q))  # 더 긴 값으로 갱신한다
    return enq, maxq                        # (큐에 넣은 횟수, 큐 길이의 최댓값)

# 표시 시점을 바꿔 두 번 실행하고 각각 출력한다
print("enqueue", bfs_count(OPEN4, (0, 0), "enqueue"))
print("dequeue", bfs_count(OPEN4, (0, 0), "dequeue"))

# T2 · 시작 상태: 두 컨테이너를 n마다 새로 만든다. 시간은 환경마다 다르므로 배수(비율)만 본다.
import time  # 시간을 재는 도구

# 원소 n개를 앞에서부터 모두 꺼내는 데 걸린 시간을 돌려준다.
def drain_list(n):
    a = list(range(n))  # 0부터 n-1까지 든 리스트
    t = time.perf_counter()  # 시작 시각
    while a:  # 비어 있지 않은 동안 반복한다
        a.pop(0)  # 맨 앞(0번) 원소를 꺼낸다
    return time.perf_counter() - t  # 끝 시각 - 시작 시각

# 같은 일을 deque로 하고 걸린 시간을 돌려준다.
def drain_deque(n):
    d = deque(range(n))  # 같은 값이 든 deque
    t = time.perf_counter()  # 시작 시각
    while d:
        d.popleft()  # 맨 앞 원소를 꺼낸다
    return time.perf_counter() - t  # 끝 시각 - 시작 시각

# n마다 (list 시간, deque 시간)을 담은 딕셔너리
# 아래 출력은 '큰 n의 시간 / 작은 n의 시간' 비율이다.
t = {n: (drain_list(n), drain_deque(n)) for n in (10000, 100000)}
print("첫 번째:  n이 10배가 될 때 시간은", round(t[100000][0] / t[10000][0], 1), "배")
print("두 번째:  n이 10배가 될 때 시간은", round(t[100000][1] / t[10000][1], 1), "배")
print("n=100000에서 (list 시간) / (deque 시간) =", round(t[100000][0] / t[100000][1], 1))

import sys  # 파이썬 시스템 정보를 쓰는 도구

# 재귀: 이웃 칸마다 자기 자신을 다시 불러 이어진 땅을 따라간다.
def explore_rec(grid, r, c, seen):
    seen.add((r, c))  # 지금 칸을 방문했다고 표시한다
    # 땅('1')인 이웃 칸만 본다

    # try/except: try 안에서 오류가 나도 멈추지 않고 except 쪽을 실행한다
    try:
        explore_rec(["1" * width], 0, 0, seen)
        print(width, "방문한 칸:", len(seen))
    except RecursionError as e:  # 재귀 오류를 잡아 e에 담는다

# T4(선택) · 시작 상태: 첫 호출은 새로 시작한 상태이고, 이어지는 두 호출은 같은 프로세스에서 이어서 실행한다.
# g에서 u부터 DFS로 방문 순서를 만들어 돌려주는 함수(dfs_bad)이다.
def dfs_bad(g, u, visited=set()):
    visited.add(u)
    order = [u]  # u부터 순서에 담는다
    for v in neighbors(g, u):  # u의 이웃을 하나씩 본다
        if v not in visited:
            order += dfs_bad(g, v, visited)  # 이웃 쪽 탐색 결과를 뒤에 이어 붙인다
    return order  # 방문 순서를 돌려준다

# 같은 함수를 세 번 호출해 결과를 출력한다
print(dfs_bad(g, "A"))
print(dfs_bad(g, "A"))
print(dfs_bad(g, "B"))

A9 · 같은 미로에서 깊이 우선과 비교9분 · 짝

같은 MAZE에서 재귀로 처음 찾은 길의 간선 수를 구해 A7에서 구한 값과 비교한다. first_path_len은 완성본이 제공된다. 이번에는 방향 순서 24가지를 모두 돌려 DFS 값과 BFS 값이 각각 어떻게 변하는지 한 번에 출력한다. 실행하기 전에 활동지 2부 A9의 예측 칸을 먼저 채우고, 출력에서 골라 표에 옮겨 쓴다.

학습 내용 · DIRS 순서와 24가지 실험
  • DIRS는 grid_neighbors가 이웃을 내주는 방향 순서(기본 우·하·좌·상)이다. 방향이 4개이므로 순서의 경우의 수는 4×3×2×1 = 24가지이다. 출력의 우하좌상은 방향 순서를 첫 글자 순서로 쓴 것이다.
  • first_path_len은 재귀 DFS가 목표 칸에 처음 닿았을 때의 간선 수(걸음 수)를 돌려준다. 완성본이므로 읽기만 하고 아래 실행 틀을 실행한다.
  • 실행 틀은 방향 순서마다 DIRS를 바꿔 BFS 값(shortest_path_len)과 DFS 값(first_path_len)을 함께 구한다. 출력은 첫 줄이 BFS 값의 종류이고, 이어서 방향 순서 이름과 DFS 값이 24줄 나온다.
  • 하는 방법: 실행하기 전에 24가지 중 DFS 값이 BFS 값과 같아지는 순서가 몇 가지일지 숫자로 예측해 활동지 2부 A9에 쓴다. 실행한 뒤 같은 순서 2개와 다른 순서 2개를 표에 옮기고, DFS 값이 같은 순서끼리 묶어 규칙을 찾는다.

제공 코드(완성본)

# A9 제공(완성본) · 시작 상태: seen은 호출마다 새로 만든다. dirs 순서대로 이웃을 본다.
# 재귀(DFS)로 처음 닿은 길의 간선 수를 구한다. dirs 순서대로 이웃을 본다.
def first_path_len(grid, start, goal, dirs):
    seen = set()  # 이미 지난 칸 모음

    # 안쪽 함수: 지금 칸 (r, c)까지 steps칸 왔다고 보고 이어 간다
    def go(r, c, steps):
        if (r, c) == goal:  # 목표에 닿았는가
            return steps  # 지금까지의 간선 수를 돌려준다
        seen.add((r, c))  # 지난 칸으로 표시한다
        for dr, dc in dirs:
            nr, nc = r + dr, c + dc  # 다음 칸 후보
            # 격자 안이고, 벽이 아니며, 아직 안 간 칸이면 이동한다
            if 0 <= nr < len(grid) and 0 <= nc < len(grid[0]) and grid[nr][nc] != "#" and (nr, nc) not in seen:
                res = go(nr, nc, steps + 1)  # 그 칸에서 이어서 찾는다
                if res is not None:  # None은 '값 없음'이다. 길을 찾았는가
                    return res  # 찾은 값을 그대로 위로 전달한다
        return None  # 이 칸에서는 길을 못 찾았다

    return go(start[0], start[1], 0)       # 목표에 처음 닿을 때의 간선 수(닿지 못하면 None)

# A9 실행 틀 · 방향 순서 24가지를 모두 돌려 DFS 값과 BFS 값을 출력한다(출력 값은 적혀 있지 않다).
# 위에서 정의한 first_path_len, 1부의 shortest_path_len, MAZE, START, GOAL을 그대로 쓴다.
# permutations: 네 방향의 모든 나열(24가지)을 하나씩 내주는 도구
from itertools import permutations
BASE = [(0, 1), (1, 0), (0, -1), (-1, 0)]                 # 우 하 좌 상
NAME = {(0, 1): "우", (1, 0): "하", (0, -1): "좌", (-1, 0): "상"}   # 출력에 쓸 이름
bfs_lens = set()   # BFS 값을 모은다(같은 값은 한 번만 담긴다)
dfs_lens = {}      # {방향 순서 이름: DFS가 처음 찾은 길의 간선 수}
for p in permutations(BASE):
    DIRS = list(p)                 # grid_neighbors가 읽는 전역 DIRS를 바꾼다
    bfs_lens.add(shortest_path_len(MAZE, START, GOAL))
    dfs_lens["".join(NAME[d] for d in p)] = first_path_len(MAZE, START, GOAL, list(p))
DIRS = BASE                        # 실험이 끝나면 원래 순서로 되돌려 둔다
print("BFS 값의 종류:", bfs_lens)
for name, v in dfs_lens.items():
    print(name, v)

DFS 값이 같은 순서끼리 묶어 보면 규칙이 보일 수 있다. 출력은 방향 순서 이름(예: 우하좌상)과 DFS 값이다.
