사용법#how

  1. 각 활동의 ‘내 코드’ 편집기에서 코드를 쓰고 [▶ 실행] 또는 Ctrl(⌘)+Enter로 확인한다. [예시 코드]에서 필요한 코드를 [편집기에 추가]하면 편집기 맨 아래에 이어 붙는다. 이 페이지에서는 따로 파이썬을 설치하지 않는다(코드 실행은 인터넷 연결이 필요하다).
  2. 같은 쪽(페이지)의 편집기들은 파이썬 환경을 공유한다. 앞 편집기에서 실행한 함수와 변수를 뒤 편집기에서 쓸 수 있다. 추가 순서는 ‘골격(내가 채움) → 자체 테스트’이다. 테스트 블록은 내 함수를 완성한 뒤 맨 아래에 추가해 실행한다.
  3. 다른 쪽의 코드(1부 파일 등)가 필요하면 먼저 그 쪽 편집기에서 실행해 성공시킨다. 그다음 이 쪽 편집기의 [앞 쪽 코드 불러오기]를 누른다. NameError는 아직 정의하지 않은 이름을 썼다는 뜻이니, 그 이름을 정의한 코드를 먼저 실행한다.
  4. 한 번의 실행은 15초를 넘기면 멈추고 환경이 초기화된다. 아직 채우지 않은 곳은 NotImplementedError, 테스트 실패는 AssertionError로 나온다.
  5. 편집기의 내용은 [저장(JSON)]으로 저장되어 제출된다(.py 파일을 따로 만들지 않는다).
  6. 이 파일은 3차시(A11 시작 때 배포)에 사용한다. 접어 둔 부분(details)은 안에 적힌 때가 되면 직접 연다. 접힌 부분은 [예시 코드]에도 나타나지 않으므로, 열어서 코드를 사용한다. 오류 코드(B1, B2, B4)는 각 활동 아래의 학습 내용 상자에 있다.
