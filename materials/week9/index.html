자료를 열어야 하는 때가 정해져 있다. 각 자료에 적힌 사용 시점이 되기 전에는 열지 않는다. 특히 붉은 표시의 자료는 표시된 활동을 시작하기 직전까지 열지 않는다. 미리 보면 스스로 생각해 볼 기회가 사라진다.

각 자료에는 파란 “학습 내용” 상자(활동 전·중에 읽는다)와 초록 “활동을 마친 뒤 열어 확인한다” 상자(먼저 자기 말로 쓴 뒤 연다)가 있다. 모든 입력은 화면에서 하고 [저장(JSON)]으로 제출한다. 코드 실행은 인터넷 연결이 필요하다.

입력하고 제출하기입력 → 저장 → 제출

  1. 입력: 화면의 입력란에 쓰고, 위쪽 저장 바에 학번과 이름을 쓴다.
  2. 저장: [저장(JSON)] 단추를 누르면 JSON 파일 한 개가 내려받아진다.
  3. 제출: 내려받은 JSON 파일을 안내받은 방법(예: LMS)으로 낸다. 파일마다 한 번씩 한다.

이번 주차에 저장·제출하는 파일은 모두 5개이다(rubric.html은 읽는 자료라 제출하지 않는다).

실습 과제의 최종 코드와 복잡도 서술은 3차시 자료(student_code_lab_part2.html)의 JSON에 담긴다.

시간이 모자라면 [임시 저장]을 눌러 파일을 내려받아 둔다. 다음에 같은 파일을 열고 [불러오기]로 그 파일을 고르면 쓴 내용이 돌아와 이어 쓸 수 있다. 임시 저장 파일은 제출 파일이 아니다. 다 쓴 뒤 [저장(JSON)]으로 만든 파일(파일명에 “임시저장”이 없는 것)을 낸다.
