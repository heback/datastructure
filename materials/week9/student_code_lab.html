사용법#how

  1. 각 활동의 ‘내 코드’ 편집기에서 코드를 쓰고 [▶ 실행] 또는 Ctrl(⌘)+Enter로 확인한다. [예시 코드]에서 필요한 코드를 [편집기에 추가]하면 편집기 맨 아래에 이어 붙는다. 이 페이지에서는 따로 파이썬을 설치하지 않는다(코드 실행은 인터넷 연결이 필요하다).
  2. 같은 쪽(페이지)의 편집기들은 파이썬 환경을 공유한다. 앞 편집기에서 실행한 함수와 변수를 뒤 편집기에서 쓸 수 있다. 추가 순서는 ‘공통 코드 → 골격(내가 채움) → 자체 테스트’이다. 테스트 블록은 골격을 채운 뒤 맨 아래에 추가해 실행한다.
  3. 다른 쪽의 코드가 필요하면 먼저 그 쪽 편집기에서 실행해 성공시킨다. 그다음 이 쪽 편집기의 [앞 쪽 코드 불러오기]를 누른다. NameError는 아직 정의하지 않은 이름을 썼다는 뜻이니, 그 이름을 정의한 코드를 먼저 추가해 실행한다.
  4. 한 번의 실행은 15초를 넘기면 멈추고 환경이 초기화된다. 무한 반복이 없는지 확인한다. 테스트가 실패하면 AssertionError가 나오고, 아직 채우지 않은 곳은 NotImplementedError로 알려 준다. 이는 아직 채울 곳이 남아 있다는 뜻이다.
  5. 편집기의 내용은 [저장(JSON)]으로 저장되어 제출된다(.py 파일을 따로 만들지 않는다). 배열의 칸 번호는 0부터 센다. 힙은 모두 최소 힙(부모 ≤ 자식)이다.

def parent(i):
    return (i - 1) // 2

def sift_up(h, i):
    swaps = 0
    while i > 0:
        p = parent(i)
        if h[p] > h[i]:
            h[p], h[i] = h[i], h[p]
            swaps += 1
            i = p          # 올라간 칸에서 다시 비교한다
        else:
            break
    return swaps

자주 나오는 실수: 자리를 바꾼 뒤 i를 부모 칸으로 옮기지 않아 같은 칸에서 끝없이 반복한다. 값을 맨 끝이 아니라 맨 앞에 붙인다. 테스트를 통과했어도 내 코드와 줄 단위로 비교한다.

활동을 마친 뒤 열어 확인한다 · A8 도전 정답 코드
def left_child(i):
    return 2 * i + 1

def right_child(i):
    return 2 * i + 2

def sift_down(h, i):
    n = len(h)
    while True:
        s = i
        l, r = left_child(i), right_child(i)
        if l < n and h[l] < h[s]:
            s = l
        if r < n and h[r] < h[s]:
            s = r
        if s == i:
            break
        h[i], h[s] = h[s], h[i]
        i = s

def my_heapify(h):
    for i in range(len(h) // 2 - 1, -1, -1):
        sift_down(h, i)

자식 칸이 배열 길이를 넘는지 먼저 확인해야 범위 오류가 나지 않는다. 마지막 부모부터 시작하는 이유는 그보다 뒤의 칸이 리프라 이미 약속을 만족하기 때문이다. 입력에 같은 값이 있으면 heapq.heapify와 배열이 달라도 둘 다 올바른 힙일 수 있다.

A9 · heapq 관찰과 B310분 · 개인

활동지 A9의 예측을 먼저 쓴 뒤 아래 코드를 실행해 실제 값을 쓴다. 코드는 heappush, heappop, heapify, h[0]만 쓴다. 코드는 아래 '내 코드 · A9' 편집기에서 [예시 코드] → [편집기에 추가] → [▶ 실행]으로 실행한다. 예측을 쓰기 전에는 실행하지 않는다.

import heapq  # 표준 힙 도구 모듈을 불러온다

h = [9, 4, 7, 1, 8, 2, 6, 3, 5]  # 처음 리스트
heapq.heapify(h)  # h를 제자리에서 힙으로 만든다
print(h)
print(h[0])  # h[0]은 0번 칸의 값이다
print(h[-1])  # h[-1]은 맨 뒤 칸의 값이다
print(h == sorted(h))  # sorted(h)는 정렬한 새 리스트, ==는 같은지 비교

out = []  # 꺼낸 값을 차례로 담을 리스트
while h:  # 리스트가 비어 있지 않은 동안 되풀이한다
    out.append(heapq.heappop(h))  # heappop이 꺼낸 값을 out 뒤에 붙인다
print(out)  # 꺼낸 순서를 출력한다

오개념 코드 B3

아래 코드를 실행하고 y가 왜 그런 값이 되는지 한 줄로 설명해 본다(활동지 A9).

import heapq

x = [5, 3, 1]  # 정수 3개가 든 리스트
y = heapq.heapify(x)
print(y, x)  # y와 x의 값을 함께 출력한다

[예시 코드]에서 A9 코드와 B3 코드를 [편집기에 추가]해 실행한다. A9 코드를 실행한 뒤에는 편집기의 내용을 모두 지우고 B3 코드를 추가해 실행한다. 결과를 활동지 A9에 옮긴다. 이 편집기의 내용이 그대로 저장된다.

질문: 최댓값이 필요하다면 이 도구로 어떻게 해야 할까? 지금은 가설만 활동지 A9에 쓰고, 3차시에 확인한다.

  • 구현 범위의 세부 안내(제출 함수 안에서 쓸 수 있는 도구)는 A12 이후 3차시 자료에서 안내한다.
