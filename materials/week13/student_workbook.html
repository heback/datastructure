이론 정리 · 배경 지식

이 상자는 활동에 필요한 말과 도구를 미리 읽는 곳이다. 활동의 답이나 오늘의 일반화는 없다. 그것은 활동으로 직접 찾는다.

  • 동적 계획법(DP)은 큰 문제의 답을 작은 문제의 답으로 나타내고, 구한 작은 문제의 답을 저장해 두고 다시 쓰는 설계 방법이다.
  • 탐욕 알고리즘(Greedy)은 매 단계에서 지금 가장 좋아 보이는 선택 하나를 하고 그 선택을 바꾸지 않는 방법이다. 예: 시험 시간이 모자랄 때 가장 쉬운 문제부터 푼다.

핵심 용어

  • 상태: 작은 문제 하나를 구별하는 값(예: 어떤 n). 전이(점화식): 한 상태의 답을 더 작은 상태의 답으로 나타내는 규칙. 기저 상태: 더 쪼갤 수 없어 답을 바로 아는 상태.

작은 예 · 1부터 n까지의 합

T(n) = 1 + 2 + … + n 을 T(n) = T(n−1) + n, T(0) = 0 으로 나타낸다. 기저 상태는 T(0)이다. 아래 두 코드는 같은 값을 다른 방향으로 구한다. 첫째는 재귀로 내려가며 구한 답을 dict에 적어 두고, 둘째는 작은 n부터 반복문으로 표를 채운다.

# 재귀로 내려가며, 구한 답은 memo(dict)에 적어 둔다.
def tri(n, memo):
    if n == 0:                 # 기저 상태
        return 0
    if n in memo:              # 이미 구한 답이면 그대로 쓴다.
        return memo[n]
    memo[n] = tri(n - 1, memo) + n
    return memo[n]

print(tri(4, {}))              # 10
# 작은 n부터 표 t를 순서대로 채운다.
t = [0] * 5                    # t[0] = 0 (기저)
for i in range(1, 5):
    t[i] = t[i - 1] + i
print(t)                       # [0, 1, 3, 6, 10]

파이썬 도구

  • dict: k in memo로 있는지 묻고 memo[k]로 꺼내는 표. 평균적으로 한 번에 찾는다.
  • 리스트 표: [0] * (n + 1)로 0번부터 n번까지 칸을 만들고 for i in range(1, n + 1)로 순서대로 채운다.
  • 무한대: 만들 수 없는 경우를 나타낼 때 INF = float('inf')를 쓴다. 어떤 수와 견줘도 INF가 더 크므로 min(3, INF)는 3이다.
  • functools.lru_cache: 함수 위에 @lru_cache(maxsize=None)를 붙이면 인자별 결과를 자동으로 기억한다.
  • 재귀 깊이: 파이썬은 재귀 호출을 약 1000겹까지만 허용한다. 큰 n을 재귀로 풀면 오류가 날 수 있다.

복잡도 표기 읽는 법

  • O(n)은 입력 크기 n이 커질 때 일의 양이 n에 비례해 늘어난다는 뜻이다. O(n²)은 n이 2배가 되면 일이 약 4배, O(2ⁿ)은 n이 1 늘 때마다 일이 2배가 된다는 뜻이다.
  • 표 크기만큼 메모리도 쓴다. 시간을 줄이는 대신 저장 공간을 쓴다는 점을 함께 읽는다.

A2 · fib(6) 호출 트리 그리기1차시 · 12분 · 개인

산출물: 호출 트리, n별 호출 횟수 표, 전체 호출 수와 서로 다른 입력의 수

약속 · 계산 규칙

fib(n) = fib(n−1) + fib(n−2), 기저 fib(0) = 0, fib(1) = 1. 호출 순서는 fib(n−1)을 먼저 부르는 왼쪽 가지 우선이다. 한 번 불리면 호출 1회로 센다. 왼쪽 가지(fib(5))를 먼저 그리고 오른쪽 가지(fib(4))를 그린 뒤 합산한다.

학습 내용 · 호출 트리를 그리고 세는 방법

fib(n)이 불리면 fib(n−1)을 먼저(왼쪽 가지), 그다음 fib(n−2)를 부른다. n이 0 또는 1이면 더 부르지 않고 멈춘다. 함수가 불릴 때마다 노드 하나를 그린다. 작은 보기 fib(3)은 이렇게 그린다(노드 5개).

fib(3)
├─ fib(2)
│   ├─ fib(1)
│   └─ fib(0)
└─ fib(1)
n0123합계
fib(3) 트리에서 불린 횟수12115
  • 트리의 노드 하나가 호출 1회이다. 위 보기의 호출은 5번이고, 서로 다른 입력(n의 종류)은 0, 1, 2, 3의 4개이다. 호출 횟수와 서로 다른 입력의 수는 다른 수이다.
  • 같은 n이 다시 불려도 노드를 새로 그린다. 한 번만 그리면 호출 수가 줄어든다.
  • 왼쪽 가지(fib(5))를 먼저 그리고 오른쪽 가지(fib(4))를 그려 합친다. 막히면 fib(3)부터 그려 올라간다. 줄과 들여쓰기로 그려도 된다.

A2와 같은 fib(6)을 다시 호출한다. 다만 계산한 값은 메모에 적고, 이미 메모에 있으면 계산하지 않고 바로 쓴다. 호출 순서는 왼쪽 가지 우선이다. 호출이 불릴 때마다 한 줄에 한 호출씩 적고, 실제로 계산했으면 C, 메모에서 바로 답했으면 H를 고른다. 호출이 끝난 가지 아래는 더 부르지 않는다. fib(0), fib(1)도 처음 불릴 때는 메모에 없으므로 C로 센다(값을 적어 두고 돌려주는 일도 계산 1회로 본다). 칸이 남으면 비워 둔다.

학습 내용 · 메모 규칙으로 호출 순서 적는 보기와 용어
  • 호출 횟수는 불린 총 횟수이다. 메모에서 바로 답한 호출도 센다. 계산 횟수(C)는 메모에 없어서 실제로 계산한 호출만 센 수이다. 메모에서 바로 답한 호출이 H이다.
  • H인 호출은 그 아래 가지를 더 부르지 않는다. fib(0), fib(1)도 처음 불릴 때는 C이다.

약속 · DP 규칙

dp[a] = a원을 만드는 최소 동전 개수. dp[0] = 0. 표는 0원부터 위에서 아래로 채운다. 동전은 [1, 3, 4]이다. dp[a]를 정하는 방법은 표를 채우기 전에 아래 칸에 내 말로 먼저 쓴다.

학습 내용 · dp 규칙의 보기
  • dp[a]는 a원을 만드는 최소 동전 개수이고 dp[0] = 0이다. 값은 동전의 종류가 아니라 개수이다.
  • a 이하의 모든 동전 c에 대해 “(a−c)원의 최소 개수 + 1”을 후보로 놓고, 그중 가장 작은 값을 dp[a]로 한다. c가 a보다 크면 그 후보는 없다.

보기: 동전 [1, 2]로 dp[3] (과제 체계가 아닌 다른 체계이다). 이미 dp[0] = 0, dp[1] = 1, dp[2] = 1이다.

c = 1 → dp[2] + 1 = 2
c = 2 → dp[1] + 1 = 2
dp[3] = min(2, 2) = 2

표를 채우기 전에 dp[6]을 만들 때 마지막으로 낸 동전이 4일 때, 3일 때, 1일 때 그 앞에 만들어 둔 금액은 각각 몇 원인가? 세 경우를 보고 dp[6]을 정하는 방법을 내 말로 쓴다.

쓰는 법 ① 세 금액(앞에 만들어 둔 금액, 단위 원)을 숫자로 쓰고 ② dp[6]을 정하는 방법을 2~3문장으로 쓴다.

쓰는 법 여섯 칸 모두 숫자만 쓴다. 호출 수는 불린 총 횟수, 서로 다른 입력의 수는 n의 종류 수, 계산 수는 C의 수, Greedy·dp 값은 동전 개수이다. 내 A2~A5 표에서 찾아 옮긴다.

메모 규칙의 실제 계산 수

학습 내용 · 오늘 쓰는 다섯 가지 이름
  • 메모이제이션 계산한 값을 적어 두었다가 같은 입력이 오면 다시 계산하지 않고 쓰는 방법의 이름이다.
  • 타뷸레이션 작은 값부터 표(table)를 채워 올라가 답을 얻는 방법의 이름이다.
  • 동적 계획법(DP) 메모이제이션과 타뷸레이션을 함께 부르는 이름이다.
  • 탐욕 알고리즘(Greedy) 매 단계에서 지금 가장 좋아 보이는 선택(예: 가장 큰 동전)을 하는 방법의 이름이다.
  • 반례 Greedy의 개수가 최소 개수와 다른 금액 하나처럼, 어떤 주장이 늘 맞지는 않음을 보이는 사례 하나이다.

이름은 지금까지 한 일에 붙이는 꼬리표이다. 어느 이름이 더 좋다는 판정은 아직 하지 않는다. ‘기억’이 들어간 일과 ‘선택하고 안 돌아본다’가 들어간 일을 찾아 연결한다.

② 이름 붙이기

아래 상자에 다섯 가지 이름의 뜻이 있다. 오늘 한 활동 중 어느 것에 어떤 이름이 붙는지 내 말로 연결해 쓴다.

쓰는 법 칸마다 한 문장으로 쓴다. 오늘 한 활동의 번호(A○)와 그때 한 일을 함께 쓴다. 형식 예(다른 이름): 이진 탐색은 12주차에 구간을 반으로 줄여 가며 찾은 일에 붙는 이름이다.

이 질문에 A2·A3에서 내가 센 수(호출 수와 계산 수)를 근거로 한 문장으로 답한다.

쓰는 법 한 문장으로 쓴다. A2·A3에서 센 숫자(호출 수) 두 개를 문장에 넣는다.

핵심

(선택) 방금 한 일 중 ‘기억’이 들어간 것은 무엇인가? ‘한 번 고르면 돌아보지 않는다’가 들어간 것은 무엇인가?

쓰는 법 (선택) 두 줄로 쓴다. 1줄: 기억이 들어간 일. 2줄: 한 번 고르면 돌아보지 않는 일. 없으면 ‘없다’라고 쓴다.

③ exit ticket

쓰는 법 숫자만 쓴다(번 단위는 적혀 있다). 9원·fib(7)은 오늘 표에 없는 값이므로 규칙으로 직접 구한다.

2[1, 3, 4]에서 9원의 Greedy 개수 , dp[9]

(선택) 오늘 헷갈린 말 한 개와 그 까닭을 쓴다.

쓰는 법 (선택) 헷갈린 말 한 개와 까닭 한 문장을 쓴다. 헷갈린 것이 없으면 ‘없음’이라 쓴다.

활동을 마친 뒤 열어 확인한다 · 사실 정리와 exit ticket 확인
  • fib(6) 순수 재귀는 호출 25번, 서로 다른 입력 7개이다. 메모 규칙은 호출 11번, 계산 7번이다. [1, 3, 4]의 6원은 Greedy 3개(4+1+1), 최소 2개(3+3)이다.
  • exit ① fib(7)을 메모 규칙으로 구하면 호출 13번, 계산 8번이다.
  • exit ② [1, 3, 4]의 9원은 Greedy가 4+4+1로 3개, dp[9]도 3개(예 3+3+3)로 같다. 6원은 달랐지만 모든 금액이 다른 것은 아니다.
  • 이름 연결의 한 예: 메모이제이션은 A3의 값 적어 두기, 타뷸레이션은 A5의 작은 금액부터 표 채우기, 탐욕 알고리즘은 A4의 가장 큰 동전부터 내기, 반례는 6원이다. 동적 계획법은 앞의 둘을 묶은 이름이다.
