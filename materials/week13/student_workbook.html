A2 · fib(6) 호출 트리 그리기1차시 · 10분 · 짝

산출물: 호출 트리, n별 호출 횟수 표, 전체 호출 수와 서로 다른 입력의 수

약속 · 계산 규칙

fib(n) = fib(n−1) + fib(n−2), 기저 fib(0) = 0, fib(1) = 1. 호출 순서는 fib(n−1)을 먼저 부르는 왼쪽 가지 우선이다. 한 번 불리면 호출 1회로 센다. 짝이 되어 한 명은 왼쪽 가지(fib(5)), 다른 한 명은 오른쪽 가지(fib(4))를 그린 뒤 합산한다.

A5 · 작은 금액부터 표 채우기1차시 · 10분 · 개인→짝 대조

산출물: dp 표(0~8)와 선택 동전, Greedy 표와의 차이 칸, (선택) [5, 7] 표

약속 · DP 규칙

dp[a] = a원을 만드는 최소 동전 개수. dp[0] = 0. dp[a]는 a 이하의 모든 동전 c에 대해 “(a−c)원의 최소 개수 + 1”을 구해 그중 가장 작은 값으로 정한다. 표는 0원부터 위에서 아래로 채운다. 동전은 [1, 3, 4]이다.

각 금액에서 동전 c를 하나 쓴 경우의 후보값(dp[a−c] + 1)을 쓰고(c가 a보다 크면 “-”), 가장 작은 값을 dp[a]에 쓴다. 그 값을 준 동전을 “선택 동전”에 쓴다(동률이면 모두).
