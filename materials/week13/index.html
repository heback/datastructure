코드 실습 파일 사용법편집기

코드 실습 파일(student_code_lab*.html)의 ‘내 코드’ 칸은 코드 편집기이다. 쓰고 [▶ 실행]을 누르면 그 쪽 안에서 바로 실행된다. 파이썬 설치도 .py 파일도 필요 없다.

  • 같은 쪽의 편집기들은 환경을 공유한다. 앞에서 실행한 함수와 변수를 뒤에서 쓴다. NameError는 아직 정의(실행)하지 않은 이름을 쓴 것이다.
  • 다른 쪽의 코드가 필요하면 그 쪽에서 실행을 성공시킨 뒤 새 쪽의 [앞 쪽 코드 불러오기]를 누른다. 단추는 항상 보이고, 성공한 실행 기록(8시간 보관, 새 탭에서도 유효)이 없으면 안내 문구가 나온다. 그때는 앞 쪽 편집기의 코드를 복사해 붙여 넣고 실행한다.
  • 한 번의 실행은 15초를 넘기면 멈춘다. 편집기에 둔 코드는 [저장(JSON)]에 함께 제출된다.

입력하고 제출하기입력 → 저장 → 제출

  1. 입력: 화면의 입력란에 쓰고, 위쪽 저장 바에 학번과 이름을 쓴다.
  2. 저장: [저장(JSON)] 단추를 누르면 JSON 파일 한 개가 내려받아진다.
  3. 제출: 내려받은 JSON 파일을 안내받은 방법(예: LMS)으로 낸다. 파일마다 한 번씩 한다.

이번 주차에 저장·제출하는 파일은 모두 8개이다(rubric.html은 읽는 자료라 제출하지 않는다).

시간이 모자라면 [임시 저장]을 눌러 파일을 내려받아 둔다. 다음에 같은 파일을 열고 [불러오기]로 그 파일을 고르면 쓴 내용이 돌아와 이어 쓸 수 있다. 임시 저장 파일은 제출 파일이 아니다. 다 쓴 뒤 [저장(JSON)]으로 만든 파일(파일명에 “임시저장”이 없는 것)을 낸다.
