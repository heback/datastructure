T1fib_t1(6)은 호출 25번(값 8), fib_t1(20)은 호출 21,891번(값 6765). 순수 재귀와 같은 횟수이다. 값은 맞다.함수가 불릴 때마다 memo = {}가 새로 만들어져 저장이 재사용되지 않는다. memo를 호출 밖에서 한 번 만들고 재귀 호출에 인자로 넘긴다.
T2dp_t2([1, 3, 4], 6)은 0(정답 2), dp_t2([5, 7], 3)은 0(정답 -1). dp_t2([1, 3, 4], 0)은 0으로 우연히 맞는다.초기값이 0이면 dp[a-c] + 1 < dp[a], 곧 1 < 0이 한 번도 참이 되지 않아 어떤 칸도 바뀌지 않는다. 만들 수 없는(아직 못 구한) 칸을 INF로 시작해야 min이 동작한다.
T3세 행이 모두 [1, 0, 0, 0]이다.[[0] * C] * R은 안쪽 리스트 하나를 R번 가리킨다. 한 행을 바꾸면 모든 행이 바뀐다. [[0] * C for _ in range(R)]로 행마다 새 리스트를 만든다.
T4(선택)fib_memo_t4(3000, {})은 RecursionError, fib_tab_t4(3000)은 성공(큰 정수 하나)이다.재귀는 깊이가 n에 비례해 호출 스택 한도(기본 1000)에 걸린다. 반복문은 깊이가 늘지 않는다. 한도 값은 환경마다 다를 수 있어 3000을 썼다.

8주차의 memo={} 기본 인자는 반대로 호출 사이에 값이 남아 공유되는 함정이었다. T1은 새로 만들어져 아무것도 남지 않는 함정이다.
