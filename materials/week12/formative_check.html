학습 내용 · 판단 기준과 쓰는 법
  • “가능”은 이진 탐색·bisect의 전제를 이미 만족할 때, “불가”는 전제가 깨져 있을 때, “조건부”는 추가 조치나 조건이 필요할 때이다. 근거 한 문장에는 정렬 여부나 질의 횟수를 쓴다.
  • lower bound = 처음으로 x 이상이 나오는 자리, upper bound = 처음으로 x 초과가 나오는 자리이고 각각 bisect_left, bisect_right이다. 닫힌 구간 [lo, hi]는 양끝을 포함하고, 인덱스는 0부터 센다.
  • Q3 (i)의 규칙(A2 규칙 ①~④): lo = 0, hi = 마지막 인덱스로 시작한다. mid = (lo + hi) // 2의 원소와 목표를 견주어 같으면 끝, 목표가 더 크면 lo = mid + 1, 더 작으면 hi = mid − 1로 한다. lo > hi이면 “없음”이다.

Q1 · 상황 판단

각 상황에서 이진 탐색(또는 bisect)을 쓸 수 있는지 “가능 / 불가 / 조건부” 중 하나를 고르고, 정렬 전제 또는 질의 횟수에 근거해 한 문장으로 쓰시오.

쓰는 법 판단 칸은 목록에서 하나를 고른다. 근거 칸에는 “정렬되어 있다/뒤섞여 있다” 또는 “질의가 ○번이다”를 넣은 한 문장을 쓴다.

상황판단근거 한 문장
(a) 학번이 오름차순으로 정리된 명단에서 한 학번이 있는 자리를 찾는다.
(b) 도착한 순서대로 쌓인 센서 로그(값은 뒤섞여 있음)에서 값 하나가 있는지 한 번만 확인한다.
(c) 오름차순으로 정리된 점수 목록에서 60점 이상 80점 미만인 학생이 몇 명인지 센다.
(d) 뒤섞인 데이터 10만 개에서 “이 값이 있는가?”라는 질문이 10만 번 들어온다.
