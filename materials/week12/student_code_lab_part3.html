A7의 lower_bound 보기 
def lower_bound(a, x):
    lo, hi = 0, len(a)               # 후보 범위 [lo, hi)
    while lo < hi:
        mid = (lo + hi) // 2
        if a[mid] < x:
            lo = mid + 1
        else:
            hi = mid
    return lo

key= 인자 읽기

(이름, 점수) 쌍이 점수 오름차순으로 놓여 있다. 쌍 전체가 아니라 점수만 견주고 싶을 때 key=에 점수를 꺼내는 함수를 준다. lambda s: s[1]은 s의 두 번째 값을 꺼내는 이름 없는 함수이다.

s = ("A", 70)일 때 s[1]은 무엇일까?

번호는 0부터 세므로 s[1]은 두 번째 값 70이다.
